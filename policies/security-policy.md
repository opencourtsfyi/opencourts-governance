# Security Policy

## Reporting

If you believe you’ve found a security issue affecting OpenCourts.fyi systems or automation, please open a GitHub issue with minimal sensitive detail, or contact maintainers privately if details are sensitive.

## Scope

This repo primarily contains governance and design documents. Security-sensitive items (secrets, credentials) must never be committed.

## Automation Safety

- Automated agents must self-identify.
- Generated artifacts should be reviewable and auditable.
