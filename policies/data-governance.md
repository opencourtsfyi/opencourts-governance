# Data Governance

This document describes high-level expectations for data governance.

## Principles

- Publish only legally open, reusable, redistributable data.
- Track provenance (source, retrieval timestamp, transformations, hashes).
- Document limitations and uncertainty (“truthiness evaluation”).
- Avoid publishing sensitive data (including sealed/juvenile records).
