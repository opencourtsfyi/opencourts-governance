# opencourts-governance
documentation, policies

## Repository layout

- Charter: `charter/`
	- Project charter: `charter/project-charter.md`
- Design: `design/`
	- SRS: `design/software-requirements-specification.md`
	- SDD: `design/software-design-document.md`
	- ADRs: `design/adr/`
	- Diagrams: `design/diagrams/`
- Governance policies: `policies/`
- Automation: `automation/`
	- Issue generation tooling: `automation/issue-generation/`
	- SDD generation tooling: `automation/sdd-generation/`

## How to propose changes

1. Open an issue describing the change and why it matters.
2. Submit a PR with small, reviewable edits.
3. If the change is architecture-impacting, add/update an ADR in `design/adr/`.
