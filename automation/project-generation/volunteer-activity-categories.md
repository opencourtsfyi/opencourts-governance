This file describes the different categories of volunteer activities. It will be used to classify issues.
* DevOps (managing the cloud infrastructure for OpenCourts.FYI) - example tech: terraform, Azure
* Software Development (building open source software for OpenCourts.fyi) - example tech: python, HTML, javascript
* Data Visualization (building visualizations from OpenCourts.fyi data) - ex tech: PowerBI, Tableau, D3.js
* AI (training machines to manage the OpenCourts.fyi workflows) - ex tech: Azure, DeepSeek, PyTorch
* Data Collection and Cleaning (ingesting data into Azure, creating workflows to extract/transform/load) - ex tech: Azure, Python, computer vision
* Outreach (working with courts/ legal aid / etc. to negotiate data access and terms)
