# Governance Model

This document describes the governance model for OpenCourts.fyi.

## Summary

OpenCourts.fyi is a volunteer-led project with lightweight, transparent governance.

- **Open by default:** decisions and discussion happen in public (primarily GitHub issues/PRs).
- **Consensus-seeking:** maintainers aim for consensus, with clear decision records when consensus is unclear.
- **Volunteer-sustainable:** processes are designed to minimize overhead and avoid single points of failure.
