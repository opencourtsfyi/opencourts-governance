# Roles and Responsibilities

This document summarizes roles in OpenCourts.fyi and how responsibility is shared.

## Canonical Source

The canonical definitions of roles are in the charter:
- See `charter/project-charter.md` (Sections: Organizational Structure; Roles and Responsibilities)

## Working Summary (non-canonical)

- **Maintainers**
  - Steward the repo(s), review and merge PRs, maintain uptime and automation where applicable.
  - Own operational decisions needed to keep the project healthy.

- **Contributors**
  - Propose improvements, submit PRs, raise issues, contribute documentation and analysis.

- **Users / Community**
  - Report problems, propose features, use published data responsibly, help with context.
