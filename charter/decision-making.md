# Decision-Making

This document describes how decisions are made and recorded.

## Canonical Source

Decision-making principles are defined in the charter:
- See `charter/project-charter.md` (Section: Decision-Making)

## Process (practical)

1. **Open a proposal** (GitHub issue, discussion, or PR)
2. **Gather feedback** (async comments; request review from maintainers when needed)
3. **Record the outcome**
   - If architecture-impacting: add/update an ADR in `design/adr/`
   - If policy-impacting: update relevant doc under `policies/`
4. **Implement** via PR(s) and link back to the decision record
